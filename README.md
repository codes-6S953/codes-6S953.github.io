# 6.S953 course website

This repository contains the generated static website for 6.S953, *Topics in Error-Correcting Codes for Computer Science*.

The source content and build script live in the parent `course-page` project. Regenerate this repository from that directory with:

```sh
python3 build.py --output codes-6S953.github.io
```

The published site is available at [codes-6S953.github.io](https://codes-6S953.github.io/).
